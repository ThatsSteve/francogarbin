# Dr. Franco Garbin - Portfolio Medico & Ambulatorio

Sito web ufficiale del **Dott. Franco Garbin**, Specialista in Ginecologia e Ostetricia (Mirano, VE).

## 🚀 Tecnologie utilizzate

- **React 19**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS**
- **Framer Motion** & **Lucide React**

## 📦 Installazione e Sviluppo Locale

```bash
# Installa le dipendenze
npm install

# Avvia il server di sviluppo locale
npm run dev

# Compilazione per la produzione
npm run build

# Anteprima build locale
npm run preview
```
